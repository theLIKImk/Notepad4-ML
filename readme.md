# Notepad4-ML (Notepad4-MultiLabel)

**English** | [简体中文](readme_zh_cn.md)

![Notepad4-ML](docs/Notepad4-ml-bar.png)

Notepad4-ML is a multi-tab fork of [Notepad4](https://github.com/zufuliu/notepad4),
adding a tab bar and scrollbar match markers to what was originally a
single-document lightweight editor.

- **Version**: 0.1
- **Based on upstream**: Notepad4 v26.10 (r6392, 7b269f54)
- **Upstream baseline commit**: `3afea94b18c469b95b504553a5ece1a9e4c57d9e` (2026-10-23)
- **License**: BSD 3-Clause — see [LICENSE](LICENSE) for the full text and
  [NOTICE](NOTICE) for upstream copyrights and fork scope

## Relationship to upstream

Notepad4-ML is **not** an official Notepad4 release and is **not** maintained
by the Notepad4 author. It is an independent fork:

- Upstream project: <https://github.com/zufuliu/notepad4>
- Upstream copyright belongs to Zufu Liu and all contributors
- This fork only adds the features listed below; all other behavior follows upstream

## Features added by this fork

### 1. Multi-tab editing

- Tab bar at the top showing the file name and an unsaved marker `*`
- `Ctrl+Tab` / `Ctrl+Shift+Tab` to switch, `Ctrl+W` to close, `Ctrl+N` for a new tab
- Each tab keeps its own content, undo history, caret, scroll position, encoding,
  line ending and read-only state
- File menu: Close Tab / Close All Tabs / Open in New Window
- Toolbar: Close Tab, Open in New Window

### 2. Match markers on the vertical scrollbar

- "Mark All" or "Find All" draws a marker on the real vertical scrollbar at the
  line position of every match
- Markers stay visible while scrolling
- Settings → Scroll Mark Settings configures color and opacity, persisted to the ini file

### 3. Open only in new window

- A checkbox in Settings; when enabled, both new and opened files go to a new window
- Takes effect immediately and is written to the config, surviving restarts

### 4. Open in New Window (move semantics)

- Moves the current tab's file to a new window; the original tab is then closed
- Unsaved content is carried over: it is passed through a temporary file,
  it is **not** written back to the original file and no save dialog appears
- The copy in the new window is shown as an untitled document; saving asks for a file name

## Please check upstream before reporting

Before filing an issue, **first confirm whether upstream Notepad4 has the same problem**:

1. Download the latest official Notepad4 from
   <https://github.com/zufuliu/notepad4/releases>
2. Reproduce with the same steps
3. Use this table to decide where to report:

| Symptom | Where to report |
| --- | --- |
| Reproducible in official Notepad4 (syntax highlighting, encoding, printing, lexer, etc.) | Upstream <https://github.com/zufuliu/notepad4/issues> |
| Only in Notepad4-ML (tabs, scrollbar markers, new window) | This project's issues |
| Unsure | File here first, stating whether the official build reproduces it |

Please include in your issue:

- Notepad4-ML version (the `0.1` shown in About, plus the upstream version it is based on)
- Windows version
- Steps to reproduce
- Whether it reproduces in official Notepad4

## Download and usage

The release provides a 64-bit build:

| File | Description |
| --- | --- |
| `Notepad4-ML.exe` | Main program (multi-tab build) |
| `matepath.exe` | The file browser tool shipped with upstream |
| `locale/<lang>/Notepad4-ML.dll` | UI language resources (optional, place as needed) |
| `LICENSE` / `NOTICE` | License text and upstream copyright notices |
| `README.md` / `readme_zh_cn.md` | English and Simplified Chinese documentation |

Extract everything into the same directory. The `locale` folder is optional;
without it the UI is English.

Supported languages: English, Simplified Chinese, Traditional Chinese, Japanese,
Korean, German, French, Italian, Polish, Portuguese (Brazil), Russian, Slovenian.

## Configuration

The config file is `Notepad4-ML.ini`, kept separate from upstream's
`Notepad4.ini`, so both versions can coexist without interfering with each other.

- Portable mode: the ini sits next to the exe
- Otherwise: `%LOCALAPPDATA%\Notepad4-ML\Notepad4-ML.ini`

## Building from source

This fork is built with a zig + LLVM-MinGW toolchain (the build scripts are not
part of this repository). Upstream's original build setup (MSVC / MinGW
Makefile) still works — see the
[upstream wiki](https://github.com/zufuliu/notepad4/wiki/Build-Notepad4).

Upstream dependencies: Scintilla 5.6.7, Lexilla 5.5.4, Boost.Regex 1.91.

## Known limitations

- Switching tabs loses the code-folding expand state (text, undo and bookmarks are kept)
- The tab bar uses the standard Win32 Tab control: no per-tab close button, and it
  stays light-colored in dark themes
- The two new toolbar button icons are programmatically drawn placeholders
- The Slovenian (sl) language pack is only partially translated upstream as well
